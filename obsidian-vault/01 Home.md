# Home · The banker desk

[[00 START HERE|Start]] · [[02 Rotation|Rotation]] · [[03 History|History]] · [[04 Setup|Setup]]

> [!success] Current round
> In the **Home** tab of `SUSU.html`, the banker's view shows the **current recipient**, **whole pot**, **amount received**, **amount outstanding** and **due date**. There is a real payment confirmation button beside every member.

### Banker routine

1. Verify funds have actually arrived before marking a contribution **Paid**.
2. Every member contributes to every round, including the one collecting.
3. Only tap **Confirm payout** after all contributions have been confirmed and the recipient has received the full pot.
4. Keep a JSON backup after recording money movement.

> [!tip] Want updated tables in Obsidian?
> Use **History → Markdown snapshot** in the app to export a current read-only copy. Obsidian notes do **not** live-sync with the HTML file without a plugin.

**Launch the working app:** `SUSU.html` (open externally in your browser).
