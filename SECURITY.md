# Security and data-handling notes

SUSU V1 is a local, browser-based financial activity tracker—not a bank or payment processor. No authentication, encryption at rest, server, synchronization, or independent payment verification is provided. It should not be your sole financial record.

- Never commit real member/transaction backup files to this repository.
- Keep JSON backups secure; do not share them publicly.
- Avoid entering passwords, banking credentials, account numbers, or other sensitive financial details.
- Confirm received funds in a separate trusted channel before ticking a payment.
- If you discover a security issue, contact the repository maintainer privately, rather than posting real user data in a public issue.

This is a prototype, not a security certification or independent audit.
